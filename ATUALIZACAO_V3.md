# Atualização V3 — WhatsApp + catálogo realista

## O que mudou

- Checkout envia o resumo do pedido para o WhatsApp da loja: **+55 81 99556-8320**.
- A mensagem inclui cliente, telefone, endereço, itens, quantidades, subtotal, entrega, total, pagamento, troco e observações.
- O cliente é levado para uma tela de confirmação após abrir o WhatsApp.
- Catálogo ampliado de 6 para 20 itens.
- Inclusão de produtos de marcas conhecidas e fotos reais de referência.
- Hero passou a usar produtos reais em vez de apenas emojis.
- Nova categoria **Limpeza**.
- Catálogo local passou para a chave `conveniencia24h.catalog.v2` para que os novos itens apareçam mesmo em navegadores que já tinham a V2 salva.

## Importante sobre WhatsApp

Esta versão usa o link oficial `wa.me`: o pedido é preenchido automaticamente, mas o cliente ainda precisa tocar em **Enviar** no WhatsApp. Para envio totalmente automático sem essa confirmação, será necessário integrar a **WhatsApp Business Platform / Cloud API**.

## Fotos

As fotos desta V3 são referências públicas hospedadas por sites de marcas e varejistas. Para uma loja comercial em produção, o recomendado é substituir por fotos próprias ou imagens cuja utilização comercial tenha sido autorizada pelo fabricante/distribuidor.
